## 💖 Coração Animado com Python

Animação desenvolvida em Python utilizando a biblioteca `turtle`, com efeito de batimentoss suave, corações flutuantes e partículas de brilhinhos.

Este projeto foi criado com o objetivo de explorar conceitos básicos de:

- Animação gráfica com `turtle`
- Manipulação de objetos na tela
- Loops em tempo real
- Controle de escala para simular batimentos

A aplicação cria uma janela personalizada, um coração central com efeito de pulsação e elementos animados ao redor para compor a cena.

### 🚀 Tecnologias Utilizadas

- python
- turtle
- random
- time
